Mi Laboratorio Generativo

Núcleo de Luz — Arte generativo con Canvas y JavaScript

Concepto: “Núcleo de Luz” es una composición generativa que representa la energía creativa del diseño multimedia. A través de órbitas, partículas y núcleos geométricos, se construye un sistema visual que nunca se repite exactamente igual.

Usa los botones para cambiar la paleta de color, generar una nueva composición o guardar el resultado como imagen PNG.
